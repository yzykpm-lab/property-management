## 📋 תיאור המערכת

מערכת ניהול נדלן וחכרה **מלאה בעברית** עם כל התכונות:

### ✨ **תכונות עיקריות:**

#### 1️⃣ **ניהול נכסים**
- רישום נכסים עם פרטים מלאים
- סוגי נכסים שונים (דיור, מסחרי, משרדים)
- כתוביות בעברית, שמות בעברית

#### 2️⃣ **ניהול אישורים וזכויות**
- עלייה של אישורים (היתר בניה, בטיחות גז, ביטוח, אש, רישיון HMO וכו')
- מעקב תאריכי תפוקה
- **התראה אוטומטית** על אישורים שעומדים להיפסל
- היסטוריה מלאה

#### 3️⃣ **ניהול שוכרים**
- רישום שוכרים עם פרטים מלאים
- מעקב חובות ובעיות תשלום
- סטטוס פעיל/לא פעיל
- היסטוריה של בעיות

#### 4️⃣ **ניהול ביקורים וטיפולים**
- רשימת בדיקות לביקור (checklist)
- רישום תאריך ביקור
- תיעוד מה ראה מנהל הנכס
- רישום צרכי שיפור
- **התראה** על ביקורים שלא בוצעו

#### 5️⃣ **ניהול כלכלי**
- רישום שכירות וחשבוניות
- עלויות התחזוקה וטיפולים
- דוחות הכנסות/הוצאות
- מעקב חובות

#### 6️⃣ **מערכת CRM**
- תיעוד כל תקשורת עם שוכר/לקוח
- רישום מיילים, טלפונים, פגישות
- תביעות משפטיות וספיקי פיוי
- היסטוריה מלאה

#### 7️⃣ **דשבורד בעמוד ראשי**
- **התראות בזמן אמת:**
  - אישורים שעומדים להיפסל
  - שוכרים עם בעיות תשלום
  - ביקורים שלא בוצעו
  - תביעות משפטיות פתוחות
- סיכום כלכלי
- חלוקה על נכסים

#### 8️⃣ **מערכת הרשאות:**
- **מנהל** - גישה מלאה לכל הנתונים
- **מפקח** - ניהול נכסים וביקורים מסוימים
- **מזכירות** - עדכון מסמכים, קשר עם שוכרים
- **חשבונאי** - רק תקבול, הוצאות, דוחות

## 🛠️ **טכנולוגיה**

### Backend:
- **Node.js + Express.js**
- **MongoDB** - מסד נתונים NoSQL
- **JWT Authentication** - התחברות מאובטחת
- **Bcrypt** - הצפנת סיסמאות

### Frontend:
- **React 18**
- **Tailwind CSS** - עיצוב מודרני
- **RTL Support** - עברית מלאה
- **Responsive Design** - כל המכשירים

### Hosting:
- **Render.com** - Backend חינם
- **MongoDB Atlas** - Database חינם
- **Frontend** - Vercel/Netlify
